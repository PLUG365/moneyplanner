# 設定画面「アカウント」セクションのデフォルト再び閉じる（2026-07-25）

## 背景

[account-deletion-store-compliance.md](account-deletion-store-compliance.md) の決定2により、build 34のApp Store却下（Guideline 5.1.1(v)、削除導線が発見しにくい）対応として、設定画面の「アカウント」セクションを既定で展開に変更していた。

その後、Issue #10（「設定のアカウントが開きっぱなし。常時閉にする」）が報告された。他の破壊的操作セクション（「世帯」）と挙動が異なり、画面を開くたびにアカウント削除ボタンが常時見えている状態がユーザー体験上望ましくないという指摘。

## 決定

- 「アカウント」セクションの初期状態を再び「閉じる」に変更する（`accountSectionExpanded` の初期値を `false` に戻す）
- Guideline 5.1.1(v)対応としての、世帯未参加ユーザー向けの独立した削除導線（`app/household.tsx` の「ログアウト」「アカウントを削除」リンク）は変更しない。この導線はセクション展開状態に依存しないため、却下時に問題視された「世帯未参加ユーザーが削除に到達できない」という論点には影響しない
- 世帯参加中ユーザーの削除導線（設定タブ内、今回閉じる対象）が再び発見しにくくなるリスクは残る。次回リリースでApp Store審査に提出する際は、実機で「設定 → アカウントセクションを開く → 削除」の操作が明確に行えることを確認し、必要ならApp Review Information欄で導線を明記する

## 理由

- ユーザーが誤操作防止と画面の見た目の観点から、他の破壊的操作セクションと統一した挙動（既定で閉じる）を優先する判断をした
- App Store再却下のリスクを認識した上での判断であり、再却下された場合はセクションの既定展開に戻すか、削除導線をセクション外の常設リンクとして独立させる対応を検討する
